# CatculatorApp 🐾

A purr-fectly adorable cat-themed calculator for Android, featuring meow sound effects, paw-print buttons, and live calculation previews.

## 🌟 Features

- 🐱 **Cat-Themed UI**: A cozy calculation experience with a beautiful cat background.
- 🐾 **Paw-Print Buttons**: Interactive buttons designed with a unique paw-print selector effect.
- 🔊 **Meow Sound Effects**: Every button press triggers a delightful meow sound to keep you smiling.
- 🔢 **Standard Arithmetic**: Supports Addition (+), Subtraction (−), Multiplication (×), Division (÷), and Percentages (%).
- ⚡ **Live Calculation**: Results update in real-time as you type your expression.
- ⌫ **Smart Backspace & Clear**: Easily correct individual characters or clear the entire screen with "AC".
- 📱 **Adaptive Text**: Displays dynamically adjust text size for long expressions to ensure readability.

## 🛠️ Built With

- **Kotlin** - Modern, safe, and expressive programming language.
- **Android SDK** - Built using standard Android components.
- **View Binding** - Efficient and safe interaction with UI elements.
- **MediaPlayer API** - Smooth integration of audio feedback.
- **XML Layouts** - Custom styles and selectors for a unique look and feel.

## 🚀 Getting Started

1. **Clone the repo**:
   ```bash
   git clone https://github.com/vwhosjames/Catculator.git
   ```
2. **Open in Android Studio**:
   Import the project and wait for Gradle to sync.
3. **Run the app**:
   Connect your device or start an emulator and click the "Run" button.
